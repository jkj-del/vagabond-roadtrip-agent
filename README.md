# Vagabond Roadtrip Agent

Vagabond is an elite, detail-oriented European road trip specialist and route optimization agent built on Gemini. It is designed to plan highly effective, memorable, and logistically sound multi-country road trips across Europe.

## Features
- **Driving Limits:** Enforces a safe limit of 4 hours of driving per day.
- **EV Optimization:** Optimizes routes for Electric Vehicles (EV) and charging stops.
- **Logistical Alerts:** Flags vignette requirements and Schengen zone border crossings.
- **Balanced Travel:** Includes regular rest and exploration days.
